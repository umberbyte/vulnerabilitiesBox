# Vだけのplugin IDを持つ残り26変種の原本レビュー

2026-10-05に保存済みのコアDAST中間分析、各V runの`alerts.json`と該当`messages-first-500.json`をオフラインで照合した。B0011は[別の個別レビュー](README-review-B0011.md)に記録済みで、ここでは残り26変種を扱う。全26変種に個別V/F/N合格記録はあるが、**これらの旧ZAP走査には対象アプリの実行時ソース指紋がない**。新たなスキャンや対象アプリへの通信は行っていない。原run・alertへの対応は、ローカルの[中間分析JSON](artifacts/core-dast-analysis-20261004.json)、`core-dast-20261004-{a,b,c,d}-manifest.json`と各台帳に保存されている。

| 保存アラートの性質 | 該当変種 | 原本で読めたこと | ベンチマークで残る確認 |
|---|---|---|---|
| SQL Injection `40018`、High | B0012, B0013, B0015 | すべて`POST /v4-sql`の`value`を指す。B0012/B0013は真条件で公開行が返る差分、B0015は算術形の入力で公開2行が返る。B0011以外は走査時ソース未対応付け。 | F/Nの同条件応答、保護行への影響、同一ソース・seed・依存環境での反復。アラートの公開行だけで保護値の取得としない。 |
| Reflected XSS `40012`、High | B0024, B0028, B0030, B0032, B0033, B0035, B0036, B0037, B0038, B0040 | `GET /v4-browser`の`text`に入れたスクリプト風の文字列がVの応答に反映される。B0038はVで`text/html`、F/Nで`text/plain`になる設計。 | アラート時のブラウザー実行、クリック等が必要な文脈、CSP・MIME・保存型の状態を変種ごとに確認する。HTML反映だけを実行成功とはみなさない。 |
| Remote OS Command Injection `90020`、High | B0081, B0083, B0087, B0088 | `POST /cli-workbook`の`value`に対し、Vの公開応答本文に`root:x:0:0`を含むコマンド出力が残る。B0087には下記`90035`も付く。 | 実行worker・初期状態とF/Nの同条件応答を対応付け、当該CLI境界への帰属を確認する。 |
| Path Traversal `6`、High | B0082, B0122, B0136 | `POST /cli-workbook`または`/v4-files`で`/etc/passwd`を指定したV応答に`root:x:0:0`がある。B0082の設計上の境界はffmpeg入力protocolで、plugin名だけで根本原因を置き換えない。 | F/Nの応答と保護対象ファイルの由来を確認し、当該変種の陽性条件に対応するか判定する。 |
| 式評価を別のplugin名で報告 | B0061, B0065, B0106、加えてB0087 | B0061の`90035`はテンプレート算術の結果を報告するが、保存応答は`exposed:false`。B0065の`40018`は`evalText`の`9-2`が7になる応答で、SQLクエリではない。B0106の`40018`はXML処理の`position=3-2`に対する公開出力。B0087の追加`90035`はCLI出力中の文字列であり、テンプレート環境の越境を示していない。 | 正常な式評価と、各根本原因に固有の保護値・副作用を区別する。plugin名の一致・不一致だけでTP/FPを決めない。 |
| Cross-Domain Misconfiguration `10098`、Medium | B0339 | `GET /v5-transport/local`の応答に`Access-Control-Allow-Origin: *`と`localOnlySecret`があり、アラートはそのheaderを指す。個別成立確認には実ブラウザーでの別origin読取も含まれる。 | 走査時ソース・ブラウザー条件・Private Network Accessの対応付け。headerだけをブラウザー読取の証明としない。 |
| 情報レベルの通知 | B0057, B0074 | B0057の`10031`は正常な`srcdoc`属性の潜在的XSS通知で、攻撃入力・実行証拠はない。B0074の`10104`はUser-Agent Fuzzerの情報通知で、保存応答はHTTP 422の実行制限エラーだった。 | B0057は実ブラウザー境界を別途確認する。B0074のfuzzer通知そのものを欠陥検出として数えない。 |

この表は26**変種**の分類であり、B0087が`90020`と`90035`の2種類を持つため、plugin IDの延べ出現は27である。B0011を含む保存済み中間分析のVのみ候補は27変種・延べ28種類の変種別plugin出現となる。B0057とB0074はInformationalのみで、残り25変種にはMediumまたはHighのVのみplugin IDがある。

公開応答でコマンド出力やファイル内容が確認できる候補は優先して再計測する価値がある。ただし、それらもこの資料だけでは最終TPではない。走査時の実行ソース、依存サービス、seed、対象操作の陽性条件を揃え、F/Nの対照と原要求・応答を人間が照合した後に採点する。単にVでplugin IDが増えたことを検出率の分子へ加えない。
